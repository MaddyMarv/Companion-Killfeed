### [Companion Killfeed](https://www.nexusmods.com/warhammer40kdarktide/mods/1126)
<img width="1045" height="800" alt="image" src="https://github.com/user-attachments/assets/05d51cf2-e01e-469a-b024-b95132c4e8be" />

Standalone mod that attributes companion kills (such as the Dog and Servo Skull) directly in the combat killfeed. It intercepts companion kills and replaces your player name with the companion's name, applying your character's assigned UI slot color to the feed, and even dynamically pulling your custom pet names from the ServoSkullNametag mod. You can configure it to display in a dedicated companion killfeed, choose your preferred name formatting, and toggle tracking for specific companion types.

**Options:**
- My Kills Routing [Main Feed Only, Separate Feed Only, Both Feeds, Off (Do Not Show)]
- Allied Kills Routing [Main Feed Only, Separate Feed Only, Both Feeds, Off (Do Not Show)]
- Feed Position X/Y Offset
- Max Feed Entries
- Dog Name Format [Companion Name, Type Only, Player's Companion, Companion & Player, Player Name Only]
- Skull Name Format [Companion Name, Type Only, Player's Companion, Companion & Player, Player Name Only]
- Fallback Name Format [Type Only, Player's Companion, Player Name Only]

**Feed Filters**
- Combat Kill Filters (Show Kills and Stack/Combine on Non-Elites, Bosses, or Specials)
- Companion Tracking Filters (Cyber-Mastiff Kills, Lasgun Skull Kills, Flame Skull Kills, Hacker Skull Hacks, Medic Skull Revives)
