### [Companion Killfeed](https://www.nexusmods.com/warhammer40kdarktide/mods/1126)
<img width="1045" height="800" alt="image" src="https://github.com/user-attachments/assets/05d51cf2-e01e-469a-b024-b95132c4e8be" />

Shows companion kills (Mastiff, Servo-Skull) under their own name in the killfeed instead of yours. Supports custom pet names from ServoSkullNametag.

<details>
<summary><b>Mod Settings / Commands</b></summary>

**General Settings**
- My Kills Routing [Main feed only, Separate feed only, Both feeds, Off (Do not show)]
- Allied Kills Routing [Main feed only, Separate feed only, Both feeds, Off (Do not show)]
- Horizontal Offset (X)
- Vertical Offset (Y)
- Dog Name format [Companion Name (e.g. Byte), Type Only (e.g. Cyber-Mastiff), Player's Companion (e.g. Maddy's Cyber-Mastiff Byte), Companion & Player (e.g. Byte (Maddy)), Player Name Only (e.g. Maddy)]
- Skull Name format [Companion Name (e.g. Byte), Type Only (e.g. Cyber-Mastiff), Player's Companion (e.g. Maddy's Cyber-Mastiff Byte), Companion & Player (e.g. Byte (Maddy)), Player Name Only (e.g. Maddy)]
- Fallback Name format [Type Only (e.g. Cyber-Mastiff), Player's Companion (e.g. Maddy's Cyber-Mastiff Byte), Player Name Only (e.g. Maddy)]

**Filters**
- Enemy Filters (Show kills on non-elites, bosses, or specials; Stack/Combine non-elites, bosses, or specials)
- Companion Filters (Track Cyber-Mastiff kills, Track Lasgun Skull kills, Track Flame Skull kills, Track Hacker Skull hacks, Track Medic Skull revives)
</details>
